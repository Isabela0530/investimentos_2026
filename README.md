# investimentos_2026

## Descrição
Aplicativo desenvolvido em Flutter que simula investimentos com aportes mensais. O usuário informa o valor investido por mês, o período em meses e a taxa de juros. O sistema exibe o valor acumulado sem juros e com juros compostos, permitindo comparar o crescimento do investimento ao longo do tempo.

## Como executar
1. Abra o Vs Code;
2. Procure a pasta "lib";
3. Dentro da pasta LIB clique em "main.dart";
4. Na barra embaixo procure por "No Device" ou "Windows *windows-x64";
5. Ao encontrar altere para "Chrome (web.javascript)";
6. Após alterar inicie o projeto no "Start Debugging" ou Play;
7. Se tiver realizado corretamente o projeto abrirá no chrome;
